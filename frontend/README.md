# Frontend

React, TypeScript, and Vite camera interface. Use pnpm as the package manager.

From this directory, install the locked dependencies and start the development server:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

Open the local URL printed by Vite. The frontend sends camera frames to the FastAPI service; see the root [setup guide](../setup.md) for manual backend setup and run instructions.
